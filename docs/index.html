Questions, answered.

Does it send my transcript automatically?

Not by default. Dictation inserts editable text at your cursor. Auto-submit and conversation mode can submit as part of their configured behavior.

Does audio leave my machine?

Default speech recognition and synthesis use local tools. Text normalization calls your configured LLM endpoint; hosted speech recognition is optional.

Can I use it hands-free?

Conversation mode listens, waits for the completed agent turn, speaks the reply, and listens again. You can pause or interrupt it.

Does it support Vietnamese?

VieNeu-TTS supports Vietnamese and English code-switching. Available language support depends on the selected speech engine and voice.

Which OpenCode hosts work?

The plugin supports OpenCode v1 and v2. See the installation guide for the config format and prerequisites for your host.
